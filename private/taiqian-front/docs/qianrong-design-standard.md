## 全局入口与覆盖

团队可见的规范直接写在业务应用 `apps/qianrong/UI_DESIGN_SPEC.md`，README 和列表示例均有入口，并含详情接入代码。业务仓只包含自身规范和用法，来源分析与私人路径不进入业务仓。

- `design-tokens.scss` 集中 `--qr-*` 颜色、字体、边框、尺寸、阴影及 Element 主题变量；保留已分发的 Qianrong Sans 字体和许可。
- `list-page.scss` 继续维护搜索、原生 vxe 与 Element 列表、对齐、个人中心和底栏；使用共用令牌，搜索 padding 13/14/12、卡头 52、表头 42、分页 60、操作文本 12。
- `detail-page.scss` 从当前规范接入集中详情皮肤，区块 14 圆角/54 标题行，默认三格；内容 ≥2344 四格、<940 两格、<620 一格；输入 40、只读灰底正文色、内嵌 Element 表格表头 12 中等/行 60/输入 36。
- 34 个现有新增/编辑/详情表单接入 `qr-detail-page` 和顶部标签。其它业务模块仅接入全局皮肤，保持脚本和业务字段；专门的页面头卡及模块交互只处理下表负责范围。
- `DetailHeaderCard` 只用于 7 个负责模块的查看页，当前数据生成字段，空值 `--`、0 保留、时间到分钟、状态语义标签、多字段窄卡换行；编辑元数据改为只读输入框。
- 关联系统的轻量选择组件只管理弹窗草稿，不包表格、不发请求；原生菜单树、树 ref、选中回填和提交 DTO 继续由页面维护。

## 有意保留的差异

正矿系统菜单/权限模型已经演进，qianrong 后端尚未完成。视觉采用正矿左右卡片布局，权限树保留 qianrong 原生 Element 树和选择语义，没有把新的 PermissionTable、自动保存、小程序根节点、特殊菜单禁选或正矿系统 ID 搬过来。

公共规范里的 NumberUnit、CurrencyAmount 主要用于正矿交易/仓储页，本轮负责模块没有数值单位或币种金额列。没有为了套这些组件改造其它模块的数据字段；未来这类列接入时按本应用的业务接口安排。

头像使用现有裁剪/上传流程与应用自身素材；没有复制正矿头像背景资产、帐号数据或路由。正常开发代理配置不变；验收服务是隔离 mock 入口，无代理。
