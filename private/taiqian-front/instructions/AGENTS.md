# 泰乾超级协作规则

- 此仓库是包含多个应用的 Monorepo。所有分支检查、同步、提交和推送在根目录进行；「泰乾超级-qianrong」是 apps/qianrong 子应用，不是独立 Git 仓库。
- 工作开始先读取本规则、AI_CONTEXT.md、docs/README.md 和任务相关文档，检查干净工作区后同步 dev 分支。默认开发分支为 dev（2026-10-28 用户明确）：不在 dev 且工作区干净时切到 dev 再同步，有未提交修改时先停下请用户决定；用户另行指定分支时按其指令。master 只是远端默认分支，不自动合并或切回；保留已有用户修改。
- 私人规则、文档、日志与索引按注册表 private_mounts 维护；不向业务 Git 提交链接或私人资料。数据库、缓存和运行产物不提交。
- 已有 .codegraph 时，先同步索引并用 CodeGraph 定位代码，再定向核对源码；本机配置或数据库缺失时恢复现有索引，源码改动后再次 sync/status。
- qianrong、qianlian 分别独立部署，packages 是共享包；修改 qianrong 的视觉时优先在该应用内完成，未经需求不把业务依赖带入共享包或改造 qianlian。
- 保留现有接口、查询参数、事件、权限指令、缓存键、表格 ref、分页和编辑行为。样式改造不能替换表格引擎或虚构后端支持。
- qianrong 现有 JavaScript/Vue 风格继续沿用，不做全仓格式化。公共组件修改核对所有调用方式，样式使用集中令牌。
- 修改后构建受影响应用，并以隔离示例验证交互与尺寸；纯构建不代表业务正确。使用真实数据写入或部署需要用户明确指令。
- 更新 docs 中的当前约定与 logs 中的当次记录；按默认交付规则提交、再次 pull 后 push。说明未验证部分，不因没有线上验证而扣住提交。
- 不写 AI 署名、不输出凭据、不把本机路径写成共享项目事实。
