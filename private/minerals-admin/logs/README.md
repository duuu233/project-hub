# 正矿项目（minerals-admin）私人需求与变更日志

本目录专用于记录**正矿管理系统前端**在长期维护过程中由个人发起的私人业务需求、功能调整、Bug 修复流水以及技术排障细节。

---

## 日志定位与边界

- **完全隔离**：本目录属于正矿私有资产，不与 Project Hub 统筹层全局日志混杂，其他项目的公共日志无法看到正矿内部业务细节。
- **与业务仓库关系**：本目录通过 Project Hub 的 private_mounts 挂载机制同步，本地开发或 AI Agent 在正矿项目中可直接读取与维护。
- **记录内容**：
  1. 正矿专有的业务需求背景、产品交互调整与边界条件；
  2. 每次功能迭代的改动点、受影响模块与代码提交号；
  3. 业务排障记录、类型校验已知问题及临时 workaround。
