# 正矿私有目录与文档体系接入 Project Hub 记录

- **执行日期**：2026-09-08
- **执行环境**：work（公司电脑）
- **项目**：minerals-admin (正矿)

---

## 需求背景
正矿前端作为一个团队协作 Git 仓库，团队成员 clone 仓库时不应包含个人的私有笔记、CodeGraph 数据库及内部调试文档。但在日常开发和 AI 辅助编程中，这些私有资产需要透明出现在业务代码目录树中。

---

## 实施内容
1. 在 Project Hub 中建立 private/minerals-admin/ 目录结构。
2. 接入并迁移以下资产：
   - docs/：包含架构设计、打包优化、业务领域映射与系统维护全套长期文档；
   - instructions/：保存正矿专有的 AGENTS.md 和 AI_CONTEXT.md；
   - .codegraph/：保存 33MB 的 codegraph.db 索引库及 task-cache；
   - logs/：保存正矿私有业务需求与修改日志流水。
3. 原正矿物理实体完全安全删除，并原子替换为本地链接（NTFS Junction 目录连接与 SymbolicLink 文件软链接）。
4. 在业务项目 .git/info/exclude 中注入规则，确保业务仓库 git status 完全干净。
