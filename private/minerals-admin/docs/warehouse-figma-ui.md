## 复用与接口边界

- `src/components/WarehouseUi/` 提供统计卡、详情侧栏、附件布局、表格空态和只读输入式单元格，沿用现有组件和视觉令牌。
- `metrics.ts` 中的统计值是设计静态示例。`WarehouseMetrics` 接收 `metrics` 属性替换示例，未提供时带示例说明；不能把它当成真实统计接口结果。
- 列表仍请求原接口，分页总数沿用接口结果。新增的 `uiKeyword/uiFinance/uiBusiness/uiRelease/uiOperation/uiWarehouse/uiYard` 只筛选已经返回的当前页数据，工具栏明确显示“本页筛选”。`warehouseApiQuery` 移除这些字段后才请求接口，原有高级筛选保留。接口支持全量筛选后需替换这层适配，不能声称本页筛选覆盖服务器所有数据。
- 新增/编辑沿用原有选择弹框、字典、校验、附件上传、权限和提交逻辑。新增展示字段不向后台添加未知的保存参数。出库计划附件示例数组独立于提交模型；新增已出库货物展示取可用响应字段，否则为空。
- AI 附件识别入口暂为禁用展示，普通上传继续使用 `FileUpload`。详情仅展示文件。未新增识别接口。
