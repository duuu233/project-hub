# Project Hub 日志与方案中枢

本目录汇总 Project Hub 统筹层面的操作留痕、全局项目变更与跨项目通用方案。

---

## 目录组织

| 目录 | 职责定位 | 核心文件 |
| :--- | :--- | :--- |
| **hub/** | **统筹项目自身的每一次操作留痕**（遵循子项目严格留痕规范） | ctivity.md（流水）、YYYY-MM-DD-操作.md（单次详单） |
| **projects/** | **统筹调度各业务项目的全局变更看板** | ctivity.md（全项目按时间倒序的时间线） |
| **solutions/** | **从各个小项目中学习、提炼出的跨项目通用方案库** | README.md、各类通用技术架构方案（如 private-symlink-scheme.md） |

---

## 与私有项目需求日志的边界说明

> [!NOTE]
> **凡属具体子项目的私人需求、深度业务逻辑与个人开发笔记，一律存放在 private/<project_id>/logs/ 下，与本公共目录在物理文件夹上彻底隔离。**
> 
> 例如正矿的业务提货状态机细节维护在 private/minerals-admin/logs/，既能保证正矿私人需求独立自治，又避免公共统筹层日志过于繁杂。
