# Project Hub 操作留痕：私有目录 Symlink 方案与脚本落地

- **操作日期**：2026-09-08
- **执行环境**：work（公司电脑）
- **当前分支**：main
- **执行目标**：实现 Hub 对团队项目中个人私有文件/目录的安全纳管与跨平台软链接映射

---

## 需求背景
在团队项目开发中，个人有私有文档、CodeGraph 数据库、定制 AI 规则等资产。这些内容需在本地透明读取，但不能提交到团队 Git。需要由 Project Hub 私有仓集中存储真实文件，各环境通过软链接挂载，实现一键恢复与安全隔离。

---

## 核心改动清单

1. **管理脚本与包装**：
   - scripts/setup-links.mjs：原生 Node.js ESM 实现，零第三方依赖。支持 --migrate 原子快照迁移、--detach 软链接解绑、--dry-run 演练，以及无 --project 时批量挂载当前环境所有项目。
   - scripts/setup-links.sh：类 Unix 与 SSH 环境便携入口。
2. **自动化测试套件**：
   - scripts/setup-links.test.mjs：包含 6 项单元测试，覆盖迁移字节比对、防覆盖保护、团队追踪防御、解绑保留数据与批量挂载。
3. **配置与忽略调整**：
   - projects.yaml：支持 private_mounts 配置项。
   - .gitignore：将 .codegraph/ 精确化为 /.codegraph/，使得 private/ 内部的项目级 CodeGraph 能够被 Hub 正常版本管理。
4. **正矿项目首次迁移落地**：
   - 正矿 docs/、AGENTS.md、AI_CONTEXT.md、.codegraph/ 迁移至 private/minerals-admin/。
   - 原业务目录物理实体彻底删除，替换为 Windows NTFS Junction 与 SymbolicLink。
