# 同名分支同步默认规则

日期：2026-10-09；环境：work。

用户明确：默认本地当前分支是什么名称，就拉取和推送远端什么名称；除非明确要求合并，否则只同步同名分支。具体授权示例为 `git push origin feature-v1.8.5`，不设置 upstream。

## 调整

- `AGENTS.md` 开始/结束流程改为显式 `git pull --ff-only origin <当前分支>` 和 `git push origin <当前分支>`。
- 未配置 upstream 不再单独请求确认，也不执行 `push -u`。
- origin 或远端同名分支不存在时仍停止说明；已有 upstream 的其他名称不作为改同步目标的依据。
- 保留干净工作区、快进同步、失败停止、不得自动合并/rebase/强推等约束。
- 修正文中“完成默认分支 pull”与“不自动提交或推送”两处旧表述，使其符合现有当前分支/默认提交推送规则。
- 同步正矿 Context；详细业务记录继续留在正矿私人文档中。
