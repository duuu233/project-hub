# 花盆后台

- project_id：flowerpot-admin
- 用途：花盆后台管理项目（用户指定）。
- 项目名称在各环境中保持一致；本机路径只保存在对应环境的 projects.local.yaml。

## 项目内上下文入口

以下路径均相对于目标项目根目录，接入时已核实：

- `AGENTS.md`：执行项目任务前读取的工作规则。
- `AI_CONTEXT.md`：项目已有背景；任务开始时读取最新内容。
- `.codegraph/`：本机产物，随环境而定；存在时先使用 CodeGraph 定位或理解代码，不存在时按项目自身方式检索。

Hub 只负责映射和分发，不维护本项目实现细节。每轮迭代必须读取项目自身维护的文档索引、适用规则及任务相关文档，有 CodeGraph 索引时先使用它理解或定位代码；技术栈、架构、业务规则及验证方式均以项目自身文档和实际配置为准，相关维护也在本项目内完成。

## 执行约定

- 每轮需求先检查仓库状态，核实本地默认分支和 upstream，成功 pull 后再修改；详见 Hub 的 AGENTS.md。
- 共享配置记录的远端默认分支为 `main`（依据远端 HEAD 核实）；工作分支以仓库当前检出的分支为准，没有特殊说明不切分支。
- 本次接入仅核实目录、Git 根目录和上述入口存在，未修改项目源码，也未执行构建或测试。
- 任务完成并验证通过后，默认先 `git pull --ff-only` 再 push 到当前分支的 upstream；本轮不提交或不推送时由用户明确说明。PR、合并、发布和部署仍需单独指令。
- 当次需求与验证结果记录在 Hub 的 iterations 中，长期背景优先维护项目已有上下文。
