# 相册APP

- project_id：album-app
- 用途：相册移动应用（用户指定）。
- 项目名称在各环境中保持一致；本机路径只保存在 projects.local.yaml。

## 项目内上下文入口

以下路径均相对于目标项目根目录，已确认存在：

- `AGENTS.md`：执行项目任务前读取的工作规则。
- `AI_CONTEXT.md`：项目已有背景；任务开始时读取最新内容。
- `.codegraph/`：已有索引，定位或理解代码时先使用 CodeGraph。

Hub 只负责映射和分发，不维护本项目实现细节。每轮迭代必须读取项目自身维护的文档索引、适用规则及任务相关文档，并先使用 CodeGraph 理解或定位代码；技术栈、架构、业务规则及验证方式均以项目自身文档和实际配置为准，相关维护也在本项目内完成。

## 执行约定

- 每轮需求先检查仓库状态，核实本地默认分支和 upstream，成功 pull 后再修改；详见 Hub 的 AGENTS.md。
- 默认分支未固定在共享配置中，执行时核实，不把当前分支视为默认分支。
- 本次接入仅核实目录、Git 根目录和上述入口存在，未修改项目源码，也未执行构建或测试。
- commit 和 push 均等待用户明确指令。
- 当次需求与验证结果记录在 Hub 的 iterations 中，长期背景优先维护项目已有上下文。
