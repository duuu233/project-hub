## 项目内上下文入口

- `README.md`：技术栈、环境要求与启动 / 构建命令，目前是项目唯一的公开说明入口。
- `docs/build-opt/`：打包优化相关脚本与基线数据。
- `AGENTS.md`：**不存在**，本项目尚未维护 Agent 工作规则。
- `AI_CONTEXT.md`：**不存在**，本项目尚未维护 AI 上下文文档。
- `.codegraph/`：本机产物，存在时先使用 CodeGraph 定位或理解代码；不存在时按项目自身方式检索。

Hub 只负责映射和分发，不维护本项目实现细节。由于本项目暂无 `AGENTS.md` 和 `AI_CONTEXT.md`，每轮迭代先读取 `README.md` 及任务相关源码与配置；技术栈、架构、业务规则及验证方式均以项目自身文档和实际配置为准，相关维护也在本项目内完成。是否补建项目级上下文文档由用户决定，Hub 不代为创建。

## 执行约定

- 每轮需求先检查仓库状态，核实本地默认分支和 upstream，成功 pull 后再修改；详见 Hub 的 AGENTS.md。
- 默认分支记录为 `master`（依据远端 HEAD 与本地跟踪分支核实）；实际执行前仍需确认当前工作副本状态。
- 本仓库常在功能分支上工作（接入时位于 feature 分支），不要把当前分支当作默认分支。
- 接入仅核实目录、Git 根目录和上述入口存在，未修改项目源码，也未执行构建或测试。
- commit 和 push 均等待用户明确指令。
- 当次需求与验证结果记录在 Hub 的 iterations 中，长期背景优先维护项目已有文档。
